# EndoChron

## Development

Deployed to [docker.nikhil.io](https://docker.nikhil.io). Bog-standard React + Tailwind app. Uses synthetic data (see `PROMPT.md` and `src/data/syntheticData.json`)

```bash
pnpm i
pnpm dev
```
